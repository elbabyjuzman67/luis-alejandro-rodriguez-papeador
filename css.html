CSS y títulos

Esta página muestra cómo el diseño CSS puede cambiar por completo la apariencia de una página con títulos, cajas y bloques de contenido bien estructurados.

Título principal con estilo

Usa diferentes fuentes, colores y espaciado para que los encabezados destaquen y sean legibles.

Contenido organizado

Los bloques claros y la separación entre secciones ayudan a que la página se vea más profesional y moderna.

Ejemplo de código CSS

body {
    font-family: "Segoe UI", sans-serif;
    background: #0f172a;
    color: #e2e8f0;
}

h1 {
    color: #fbbf24;
    letter-spacing: -0.04em;
}
