Cuadro comparativo: HTML vs CSS

Aspecto HTML CSS
Definición Lenguaje de marcado para crear la estructura de una página web. Lenguaje de estilos para dar apariencia y diseño al contenido.
Función principal Crear contenido y estructura. Estilizar y presentar el contenido.
Extensión .html .css
Elementos Etiquetas como <p>, <div>, <h1>, <img>. Propiedades como color, font-size, margin, padding.
Importancia Esencial para la estructura de la web. Hace que la página se vea atractiva y fácil de usar.
Tipo de lenguaje Lenguaje de marcado. Lenguaje de hojas de estilo.
